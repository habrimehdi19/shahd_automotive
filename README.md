# SHAHD AUTOMOTIVE — دليل التشغيل

هاد المشروع فيه:
- **بوت تيليغرام** كيحاور الزبون ويحجز ليه موعد بشكل تلقائي (بلا حاجة لواتساب بيزنس ولا فيريفيكيشن)
- **سيرفر** كيخزن المواعيد
- **لوحة التحكم** (نفس الصفحة ديالك) اللي كتبان فيها المواعيد الجداد لحظة بلحظة

## 1) خدم بوت تيليغرام (5 دقايق، مجاني 100%)

1. حل تطبيق تيليغرام، دور على **BotFather** وابدا معاه محادثة
2. صيفط ليه `/newbot`
3. عطيه سمية للبوت (مثلا: SHAHD AUTOMOTIVE Bot) ثم username (خاصو يسالي بـ `bot`, مثلا `ShahdAutomotive_bot`)
4. غادي يعطيك **TOKEN** (شبه: `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`) — احتفظ بيه

## 2) تثبيت المشروع

خاصك جهاز فيه Node.js مثبت (18 فما فوق)، ولا تقدر تستعمل استضافة مجانية بحال **Render** ولا **Railway**.

```bash
cd shahd-bot
npm install
```

## 3) تشغيل السيرفر

```bash
# على Mac/Linux
export TELEGRAM_BOT_TOKEN="التوكن ديالك هنا"
npm start

# على Windows (PowerShell)
$env:TELEGRAM_BOT_TOKEN="التوكن ديالك هنا"
npm start
```

غادي تشوف:
```
✅ السيرفر خدام على http://localhost:3000
✅ بوت تيليغرام خدام (polling)...
```

- حل `http://localhost:3000` فالمتصفح باش تشوف لوحة التحكم
- حل تيليغرام، دور على البوت ديالك، صيفط `/rdv` وجرب الحجز — غادي تشوف الموعد كيبان فاللوحة توتسواب (كل 5 ثواني كتجدد وحدها)

## 4) باش تخليه خدام 24/24 (اختياري)

خاصك تستضيفو (host) فسيرفر بحال:
- **Render.com** (فيه خطة مجانية) — كتزيد `TELEGRAM_BOT_TOKEN` فـ Environment Variables
- **Railway.app**
- VPS ديالك الخاص

## ملاحظات

- المواعيد كيتخزنو فملف `appointments.json` — بسيط ومباشر، ماشي قاعدة بيانات حقيقية. إلا بغيتي شي حاجة أقوى (PostgreSQL مثلا) نقدر نبدلوها منين تكبر الحاجة.
- البوت غير كيدير أسئلة بسيطة (سمية، سيارة، خدمة، وقت). إلا بغيتي يفهم بحرية أكتر (بذكاء اصطناعي)، نقدرو نزيدو ذلك.
- واتساب Business API يمكن نديروه من بعد إلا بغيتي، لكن كيتطلب حساب Meta Business موثق — تيليغرام أسهل وأسرع بزاف.
